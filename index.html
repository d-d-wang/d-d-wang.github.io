I obtained my Ph.D. in computer science in University of Central Florida, advised by Drs. Liqiang Wang and Boqing Gong. My research sits at the intersection of machine learning, computer vision, and natural language processing — specifically, how we can use vision-language models and large-scale geospatial data to understand and improve built environment for human life.

Selected Projects

Tools & Code

Open-source software and datasets from my research program.

01 / open source
WheelRoute: Wheelchair-Aware A* Routing Engine
An open-source routing engine that integrates GSV-derived accessibility scores into pedestrian graph weights, producing wheelchair-specific A-to-B routes. Used by [N] municipalities.
Python OSMnx PyTorch FastAPI
View on GitHub
02 / dataset
AccessBench: Wheelchair Accessibility Labels for 50K GSV Panoramas
A benchmark dataset of 50,000 Google Street View panoramas labeled by wheelchair users for curb ramp quality, surface condition, and sidewalk width. Enables training and evaluation of VLMs on accessibility tasks.
Dataset HuggingFace GSV Annotation
HuggingFace Dataset
03 / tool
ST-AccessAudit: Spatiotemporal Accessibility Monitoring Dashboard
An interactive web dashboard for cities to track changes in pedestrian infrastructure accessibility over time, powered by automated GSV analysis and crowdsourced reporting.
React MapLibre GL Node.js PostgreSQL
Live Demo
04 / research code
SAUC: Sparsity-Aware Uncertainty Calibration for ST-GNNs
Official implementation of SAUC (SIGSPATIAL 2024): a post-hoc framework for calibrating uncertainty in spatiotemporal Graph Neural Networks on sparse event data (traffic crashes, urban crime).
PyTorch PyTorch Geometric Uncertainty GNN
